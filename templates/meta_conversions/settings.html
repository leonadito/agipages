Envia os leads recebidos também pelo servidor para a Meta, além do Pixel do navegador — mantém os anúncios otimizados mesmo quando o navegador bloqueia ou perde o Pixel (bloqueadores de anúncio, Safari/ITP, iOS).

Onde encontrar o Access Token

No Business Manager da Meta: Gerenciador de Eventos → selecione o pixel → Configurações → API de Conversões → Gerar token de acesso. Um token de "usuário do sistema" com acesso a todos os pixels da sua conta funciona para qualquer landing page, mesmo as que usam pixels diferentes.

Para testar sem misturar com dados reais, copie o código em Gerenciador de Eventos → seu pixel → aba "Testar eventos" e cole no campo "Código de teste de eventos" acima. Remova-o depois de confirmar que os eventos estão chegando.
